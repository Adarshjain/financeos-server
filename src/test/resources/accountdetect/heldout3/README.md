# Held-out account-detection corpus v3 (heldout3, sealed only)
Fresh sealed set for a final honest score; same independent-author rules and v2 schema (incl. limitBucket, addonOf) as heldout2/README.md.
- sealed/: 24 new mailboxes (new seeds and issuer mixes), 80 to 400 mails, 3 to 8 unlocked statements each; weighted to PSU, SFB, payments banks, fintech partners.
- Extra phrasings (2 per mail type) are listed in the generator style sheets, so wording differs from v2.
- Newer traps emphasised: renames (labelled with the CURRENT name), ex-Citi to Axis, combined statements, add-ons only in a statement, closure only in a statement summary (cards and accounts), limit increases, wallets.
- Variant rule as v2: short marketed name; Amex Gold / Platinum etc. are variants; plain savings/current/debit and OneCard are null.
- All data made up; bank, domain and product names are real. Seeded generator, reproducible.
